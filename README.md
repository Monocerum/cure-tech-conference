# THE NEW AGE: Emerging Trends and Technologies in Web Development

A responsive conference website for **CURE Technologies'** web development conference, *The New Age: Emerging Trends and Technologies in Web Development*.

**Live demo:** https://monocerum.github.io/cure-tech-conference/

## About

The site presents everything an attendee needs to know about the conference: its purpose and goals, target audience, speakers, venue, and schedule. It also links to a registration page and a terms and conditions page.

The conference covers four topics:
- Artificial Intelligence in web development
- DevSecOps
- Headless CMS
- Progressive Web Apps (PWAs)

> Built as a course assignment for Web Development subject in university.

## Features

- **Hero section** with the conference title, venue, dates, and a registration button
- **About section** covering the conference purpose and goals, target audience, and key benefits
- **Key speakers** cards with photos, titles, and bios
- **Venue section** with interior and exterior photos, an embedded Google Map, and an amenities list
- **Schedule** with timed sessions, speakers, and Q&A blocks, with key talks highlighted
- **Registration page** and **Terms and Conditions page**
- **Fixed, collapsible navigation bar** with scrollspy that highlights the current section
- **Responsive layout** for desktop and mobile
- **Contact footer** with phone, email, and social links

## Tech Stack

- **HTML5**
- **CSS3** (custom styles in `style.css`)
- **Bootstrap 5.3.3** (loaded via CDN) for the navbar, layout, and scrollspy
- **Google Fonts** (Nobile, Philosopher)
- **Google Maps Embed** for the venue location
- **GitHub Pages** for hosting
